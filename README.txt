CRUNCHYGO COMPANY PROFILE

Isi folder:
- index.html             : Home, pengenalan produk, cerita berdirinya CrunchyGo, visi-misi, dan owner Nayla & Fina
- about.html             : halaman About Us, visi-misi, dan perkenalan owner
- assets/css/style.css   : desain website responsif
- assets/js/main.js      : navigasi mobile dan tahun footer

Cara menjalankan:
1. Ekstrak ZIP jika membuka dari file ZIP.
2. Buka folder crunchygo_company_profile di Visual Studio Code.
3. Buka index.html dengan ekstensi Live Server.
4. Gunakan navigasi Home untuk berpindah ke bagian Produk, Cerita Kami, Visi & Misi, dan Tim Kami.

Catatan:
- Foto menggunakan URL Unsplash sehingga membutuhkan internet.
- Nama/deskripsi produk dan teks visi-misi adalah draf yang bisa diedit sesuai kondisi sebenarnya.
- Deskripsi peran Nayla dan Fina adalah contoh awal; sesuaikan jika ada pembagian tugas yang lebih spesifik.
